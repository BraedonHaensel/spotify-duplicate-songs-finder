# Spotify Duplicate Songs Finder

This tool scans an [Exportify](https://exportify.net) CSV export of a Spotify playlist and identifies duplicate songs.

## Run Instructions

1. Use [Exportify](https://exportify.net) to export a Spotify playlist.

2. Use [pip](https://pypi.org/project/pip/) to install the required python packages:

    ```bash
    pip install -r requirements.txt
    ```

3. Use [Python](https://www.python.org/) to run the tool:

    ```bash
    python main.py
    ```
